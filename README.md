1. Penjelasan
- Membuat Dictionary produk yang berisi dengan nama, harga, dan stok
- Menggunakan while untuk perulangan agar menu pengelolaan data terus ditampilkan dan berulang
- Ngeinput pilihan menu menggunakan input() untuk memilih menu 1-5
- Untuk menampilkan data setelah perubahan bisa menggunakan kode for

2. Read, Add, Update, Delete
- Read: Menampilkan Data bisa menggunakan for key, value in produk.items() untuk menampilkan seluruh key dan value yang terdapat dalam Dictionary produk.
- Add: produk["Kategori"] = "Elektronik", digunakan untuk menambahkan key Kategori dengan value Elektronik ke dalam Dictionary.
- Update: produk.update({"harga": 2000000}) digunakan untuk mengubah value dari key harga menjadi 2000000.
- Delete: Untuk menghapus key Kategori beserta value bisa menggunakan produk.pop("Kategori")

- Untuk keluar dari program bisa menggunakan break untuk memberhentikan program dan bisa mengguanakan else jika pilihan tidak tersedia.
